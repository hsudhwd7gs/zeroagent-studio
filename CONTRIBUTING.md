# Contributing

Thanks for helping improve Brainwire!

**Full guide:** [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md)

Quick start:

```bash
git clone https://github.com/sakurablush/brainwire.git
cd brainwire
npm install
npm run dev
```

Before opening a PR:

```bash
npm run ci
```
